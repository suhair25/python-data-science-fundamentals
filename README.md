
# Python & Data Science Fundamentals

## Project Overview

This project is part of Module 1 of my Data Science internship at Codomax Digital Solutions.

The project demonstrates basic Python programming concepts through a Student Performance Analysis system.

## Objectives

- Learn Python fundamentals.
- Work with lists and dictionaries.
- Use loops, conditions, and functions.
- Calculate student performance statistics.
- Save results to a text file.
- Visualize student marks using a bar chart.

## Technologies Used

- Python
- Google Colab
- Matplotlib
- GitHub

## Features

- Displays student marks.
- Calculates average, highest, and lowest marks.
- Identifies passed and failed students.
- Counts the number of passing and failing students.
- Generates a student performance report.
- Displays student marks in a bar chart.

## How to Run

1. Open the notebook in Google Colab.
2. Run the code cells in order.
3. View the results and performance chart.
4. Download the generated student report if needed.

## Learning Outcomes

This project helps practice variables, lists, dictionaries, loops, conditional statements, functions, file handling, and basic data visualization.
